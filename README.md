# 주식/코인 브리핑 & 예측 시스템

투자 자문이 아닌 실험 프로젝트. 규칙 기반(rule-based) 시스템으로 매일 방향(상승/하락/보합) 의견을 내고, 결과와 비교하며 규칙을 점진적으로 개선한다.

## 폴더 구조

- `CLAUDE.md` — 이 프로젝트에서 지키는 행동 원칙
- `rules.md` — 현재 적용 중인 예측 규칙 (버전 관리)
- `changelog.md` — 예측이 빗나간 원인 분석과 규칙 조정 제안 로그
- `predictions/YYYY-MM-DD.md` — 그날 아침 브리핑에서 낸 예측 기록
- `results/YYYY-MM-DD.md` — 그날 마감 후 실제 결과와 비교·분석 기록
- `scripts/quant_stats.py` — 핫섹터 종목/코인의 "통계적 참고치"(변동폭 레인지, 모멘텀, 미국주식은 컨센서스 목표주가 괴리율, 코인은 24h/7d/30d 변동률) 계산 스크립트. "몇 % 오른다"는 예측이 아니라 과거 데이터 기반 참고 범위를 낸다. 아침 브리핑 작업이 매일 자동 실행.
- `portfolio/policy.md` — 모의 포트폴리오 추적 정책 (실제 자금 아님). 시장 단위(국내/미국/코인)로 하루 1건씩 방향 콜을 가상 포지션으로 기록.
- `portfolio/ledger.csv` — 모의 포지션 원장 (진입/청산/수익률/적중 여부)
- `scripts/portfolio_log.py` — 원장 open/close/summary 커맨드. 아침 브리핑(오픈+전날 청산)과 마감 비교 브리핑(국내 당일 청산)이 매일 자동 실행. 20건 이상 쌓이기 전 성과 숫자는 참고용.

## 스케줄

- **아침 7시 (매일)**: 국내/미국/코인 예측 + 어제 미국장 결과 비교 + 어제 뉴스 요약 + 핫섹터 5개 의견 → Gmail 초안 + predictions/ 기록
- **오후 5시 30분 (평일)**: 국내장 마감 결과 vs 아침 예측 비교 → Gmail 초안 + results/ 기록 + changelog.md 업데이트

## 주의

모든 예측/의견은 투자 판단 근거가 아니라 규칙 기반 시스템 검증용 실험이다.
