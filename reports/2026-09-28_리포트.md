## 0. 운영 메모

세션 시작 시 시스템이 알려준 "오늘 날짜"는 2026-09-27이었으나, 실행 시점 서버 시계(`date` 명령)를 직접 확인한 결과 UTC 2026-09-27 22:05 = KST(UTC+9) 2026-09-28(월) 07:05였다. 지침("파일명 날짜는 실행 시점의 실제 오늘 날짜(UTC+9)를 그대로 쓴다")에 따라 이 회차는 2026-09-28로 기록한다. 직전 커밋(`아침 브리핑+리포트 2026-09-27`, 일요일자)이 이미 git log·`origin/main`에 존재함을 `git fetch origin main`으로 확인해 오늘 회차와 중복되지 않음을 검증했다. 이 날짜 오프셋 현상은 2026-09-20 이래 반복되고 있어 매번 실행 시점에 직접 재확인하고 있다(PROJECT_LOG.md 8·9·16번 항목).
